# Skill Catalog

Browse and discover all your installed Claude Code skills, organized by category.

## When to Use

- User asks what skills are available
- User wants to find the right skill for a task
- User says "show skill catalog", "browse skills", "list skills", "技能目录"
- User is unsure which skill to use for a specific purpose

## How to Respond

### Option A: Open Interactive Viewer (preferred)

Use the browser to open the HTML catalog:

```
Open the interactive skill catalog at: file:///~/.claude/skills/skill-catalog/catalog.html
```

The HTML viewer provides:
- Real-time search by skill name, description, or trigger keywords
- Category filtering (sidebar + pill navigation)
- Dark/light theme with auto-detection
- Keyboard shortcuts (`/` to search, `1-9` to jump categories, `Esc` to clear)
- Mobile-responsive layout

### Option B: Display Markdown Catalog

If the browser is unavailable or the user prefers terminal reading, read and display `catalog.md` directly:

```
Read ~/.claude/skills/skill-catalog/catalog.md and present the relevant sections
```

### Option C: Search on Behalf of User

If the user asks for a specific type of skill ("What skills do I have for testing?"), search through `catalog.json` and present the matching skills:

```
Use the catalog.json data to find skills matching [user's need] and present them with descriptions and invocation methods
```

## Catalog Files

| File | Purpose |
|------|---------|
| `SKILL.md` | This file — skill definition |
| `catalog.json` | Structured data source — auto-generated by `regenerate.py` |
| `catalog.md` | Human-readable markdown catalog — auto-generated |
| `catalog.html` | Interactive browser-based viewer — auto-generated (single file, zero deps) |
| `regenerate.py` | **Auto-update engine** — scans all SKILL.md files and regenerates all outputs |
| `category-mapping.txt` | Manual skill→category assignments. Add your skills here to pin them to categories. |

## Maintenance

### When you install or remove a skill

```bash
cd ~/.claude/skills/skill-catalog
python regenerate.py
```

### What it does

1. **Scans** every `../*/SKILL.md` — reads YAML frontmatter (`name`, `description`)
2. **Categorizes** each skill:
   - If found in `category-mapping.txt` → uses that category (highest priority)
   - Else if keywords match an existing category with >= 25% similarity → auto-assigns
   - Else → **creates a brand new category** (name derived from the skill's description)
3. **Merges** built-in plugin skills (that have no local SKILL.md)
4. **Regenerates** `catalog.json`, `catalog.md`, `catalog.html` from scratch
5. **Reports** new categories, uncategorized skills, and counts

### Adding a new skill to an existing category

Edit `category-mapping.txt` and add a line:
```
my-new-skill | Content Creation
```

### Creating a new category for a skill

Edit `category-mapping.txt` and add a line with the new category name:
```
my-new-skill | AI & Machine Learning
```
Then run `python regenerate.py` — it will create the category.

### Dry-run mode

```bash
python regenerate.py --dry-run     # Preview changes without writing
python regenerate.py --verbose     # See per-skill categorization decisions
```

### Category auto-creation logic

When a skill doesn't match any existing category (similarity < 25%):
- The script extracts keywords from the skill's description
- Matches against 12 domain patterns (automation, security, database, API, deploy, docs, monitoring, AI/ML, mobile, game, design, system)
- Falls back to generating a name from the skill's own name
- The new category appears in the output with a `[NEW]` marker
